# Security

## Reporting a vulnerability

Please report vulnerabilities privately, through GitHub's
[private vulnerability reporting](https://github.com/daneelvt/keel-over-the-edge/security/advisories/new),
not in a public issue.

In scope:

- the code in this repository;
- the game at play.keelovertheedge.com, once it is online.

Reports are acknowledged within 7 days. You are credited in the advisory if
you wish.

Please do not test against other players' accounts or data, and do not run
load or denial-of-service tests against the live game.
